## Projects

### [OracleCraft](https://github.com/2cpe/OracleCraft)

A PL/SQL extension for VS Code. Adds syntax highlighting,
autocomplete, snippets, and Go-to-Definition for `.sql`, `.pls`,
`.pks`, and `.pkb` files. Built to make working with Oracle
databases less repetitive. TypeScript, TextMate grammars.

### [2cpe.github.io](https://github.com/2cpe/2cpe.github.io)

A web app for revising university exams. Subject-based question
banks for Internet Programming and Advanced Internet Technologies,
presented in a quiz interface with an Arabic (RTL) layout. Plain
HTML, CSS, and JavaScript on GitHub Pages.

### [stander-php-dashboard](https://github.com/2cpe/stander-php-dashboard)

A small PHP admin dashboard, written while learning backend
development. Admin panel, main dashboard view, and a MySQL
connection layer. PHP and MySQL, no framework. Rough in places.

### [ticket-transcripts](https://github.com/2cpe/ticket-transcripts)

A static archive of ticket conversations. Keeps a searchable
record of support interactions without a backend. Pure HTML
served from GitHub Pages.
